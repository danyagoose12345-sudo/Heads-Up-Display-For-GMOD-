## English

A custom Heads-Up Display (HUD) for Garry's Mod inspired by the classic **GTA San Andreas** style.

### ✨ Features
* Health and Armor bars styled after GTA SA.
* Weapon icon and ammo counter display.
* Classic money/points display Counter.
* Lightweight and well-optimized code.

### ⚙️ Installation
1. Download the `HUD (Copy GTA SA).zip` file from this repository.
2. Extract the archive.
3. Move the extracted folder into your Garry's Mod addons directory:
   `C:\Program Files (x86)\Steam\steamapps\common\GarrysMod\garrysmod\addons\`
4. Restart your game and enjoy!

## Русский

Кастомный HUD (интерфейс) для Garry's Mod, выполненный в узнаваемом стиле культовой игры **GTA San Andreas**.

### ✨ Особенности
* Полоски здоровья и брони в оригинальном стиле GTA SA.
* Отображение иконок оружия и счетчика патронов.
* Классический шрифт и счетчик денег/очков.
* Легкий код, который не просаживает FPS.

### ⚙️ Установка
1. Скачайте архив `HUD (Copy GTA SA).zip` со страницы этого репозитория.
2. Распакуйте архив.
3. Перенесите распакованную папку в директорию аддонов вашей Garry's Mod:
   `C:\Program Files (x86)\Steam\steamapps\common\GarrysMod\garrysmod\addons\`
4. Запустите игру и проверяйте!
